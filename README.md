Funciones del sistema

Panel del cliente

Iniciar sesión con su ID de cuenta y PIN.

Consultar sus datos y saldo disponible.

Realizar depósitos.

Realizar retiros.

Consultar el historial de sus movimientos.

Filtrar movimientos por tipo.

Consultar un resumen de sus operaciones.

Panel del administrador

Iniciar sesión como administrador.

Registrar nuevas cuentas.

Consultar las cuentas registradas.

Buscar cuentas por nombre o ID.

Filtrar cuentas según su estado.

Modificar los datos de las cuentas.

Activar o desactivar cuentas.

Eliminar cuentas.

Consultar el historial general de movimientos.

Revisar el resumen de depósitos y retiros.

Requisitos

Para ejecutar el proyecto es necesario tener instalado:

Node.js.

Visual Studio Code (recomendado).

Instrucciones para ejecutar el proyecto

1. Clonar el repositorio

git clone https://github.com/andre28-dot/MiBanco-girls.git

2. Entrar a la carpeta del proyecto

cd tu-cajero-virtual

3. Instalar las dependencias

npm install

4. Ejecutar el proyecto

npm run dev

5. Abrir la aplicación

Después de ejecutar el comando anterior, aparecerá una dirección local en la terminal. Ábrela en tu navegador para utilizar Tu Cajero Virtual.
